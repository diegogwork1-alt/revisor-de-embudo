# revisor-de-embudo

Skill gratis para Claude Code, con el método que uso en **Flowboost Marketing**.

**Qué hace:** Revisa tu embudo entero con los 6 puntos: **anuncios → landing → VSL → formulario → página de gracias → llamada en 5 minutos**. Te dice qué está bien y qué cambiar, por orden de impacto

**Qué te deja:** La revisión, en la conversación

## Instalación

```bash
git clone https://github.com/diegogwork1-alt/revisor-de-embudo.git
mkdir -p ~/.claude/skills
cp -r revisor-de-embudo/revisor-de-embudo ~/.claude/skills/
```

Si solo la quieres en un proyecto, cópiala en la carpeta `.claude/skills/` de ese proyecto.

## Cómo se usa

Abre Claude Code en la carpeta de tu proyecto y pídelo con tus palabras, por ejemplo: «Revisa mi embudo, esta es mi landing: https://…»
